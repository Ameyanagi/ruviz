# ruviz 0.14.2

GPUI plot context menus now render above ordinary host overlays, including
range shading and drag handles. **Reset View** remains clickable and restores
the viewport without firing the plot's click callback.

Hosts that capture pointer presses for their own overlays can check
`RuvizPlot::is_context_menu_open()` and leave those presses to the plot while
the menu is open. No additional feature flags are required.

The adapter guide includes a native macOS example in rexafs. Automated coverage
clicks the rendered **Reset View** entry and verifies the restored viewport.

This release also includes parallel CI checks and smaller Rust build caches.
Rust crates, Python bindings, and the npm package are aligned at `0.14.2`.

Changes: [#190](https://github.com/Ameyanagi/ruviz/pull/190) and
[#189](https://github.com/Ameyanagi/ruviz/pull/189).
