# ruviz 0.14.0

Switching between plain and Typst text now preserves the plot's font choices.
Both modes use the same preferences for generic families and the same font
settings from plots, themes, and annotations. Sans-serif text prefers Arial,
Helvetica, Liberation Sans, and Noto Sans when available. Serif and monospace
styles retain their respective families. Small differences in rasterization and
line bounds remain possible.

Rust plots gain `TextOptions` for ordered font fallbacks, language, paragraph
direction, an explicit OpenType math font, and optional missing-glyph errors.
Per-annotation options inherit unspecified plot settings. Language selects
regional Japanese, Chinese, and Korean fallback families and appropriate
right-to-left layout. `TypographyConfig::publication()` supplies the publication
font stack and enables missing-glyph errors.

Font contexts share immutable font data and have bounded glyph caches. Existing
Typst cache limits remain in place, with font settings included in cache keys.
Late font registration refreshes both renderers. Plain SVG records concrete
font choices along with fallback, language, and direction; its viewer still
needs the referenced fonts. Typst SVG and PDF provide glyph outlines.

The release also fixes clipped Å accents and tall inline math in zero-margin
Typst labels, including rotated labels, and corrects Arabic placement against
the oversized internal shaping buffer.

See the [typography guide](https://github.com/Ameyanagi/ruviz/blob/v0.14.0/docs/guide/international_typography.md) and
`examples/international_fonts.rs` for the plain/Typst comparison and usage.

## Migration

`FontConfig` and `TypographyConfig` have a new `text_options` field, and
`TextStyle` has an optional `text_options` field. Use `TextOptions::default()` or
`None` in complete struct literals; builder construction remains supported.
Generic defaults can render differently from 0.13 because both engines now use
the shared font preference list. Math keeps its separately configured font.

International fonts are installed or registered by the application; this release
does not bundle the Noto CJK collection or Arial/Helvetica. Enabling `typst-math`
shares Typst's existing embedded fonts with plain mode as well.
