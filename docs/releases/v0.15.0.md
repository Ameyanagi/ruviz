# ruviz 0.15.0

Released 2026-10-14.

Rust plots can now display RGBA images in ordinary data coordinates and sample
mathematical functions into scalar heatmaps or caller-colored images. The new
`Plot::image`, `image_with`, `heatmap_fn`, and `image_fn` methods return normal
series builders, so line and scatter overlays, axes, labels, and export work
through the existing plotting workflow.

For a scalar field with a colormap and colorbar:

```rust,check
use ruviz::prelude::*;

fn main() -> PlotResult<()> {
    Plot::new()
        .heatmap_fn(200, 200, (-2.0, 2.0, -2.0, 2.0), |x, y| {
            (-x * x - y * y).exp()
        })
        .cmap("gray")
        .aspect_equal()
        .save("field.png")?;
    Ok(())
}
```

Use `image(&pixels)` for an existing straight-alpha RGBA buffer or `image_fn`
when each function sample supplies its own `Color`. Image settings include
outer-edge extents, row origin, opacity, and nearest or bilinear interpolation.
Bilinear interpolation uses premultiplied alpha to avoid fringes at transparent
edges. Images clip to the axes and support reversed and nonlinear axes. PNG,
SVG, and PDF share image placement and sampling; SVG and PDF embed the raster
image while retaining vector axes and overlays.

The function helpers sample once at source-cell centers with a lower row
origin. Export DPI and interactive zoom reuse those samples. Scalar heatmaps
retain normalization, masking, and colorbars; caller-colored images preserve
their supplied RGBA colors.

`.aspect_equal()` gives scaled x and y units the same displayed length, keeping
unit circles circular. `.data_aspect(ratio)` selects another ratio. Both fit
the axes rectangle without changing resolved limits, including for subplots
and interactive viewports.

See the [image and complex-function guide](https://github.com/Ameyanagi/ruviz/blob/v0.15.0/docs/guide/15_image_plots.md)
and [runnable Butterworth example](https://github.com/Ameyanagi/ruviz/blob/v0.15.0/examples/complex_function.rs).
Run `cargo run --example complex_function` from the tagged checkout to generate
the grayscale magnitude plot and the phase/magnitude image below. The dashed
circle marks `|s| = 1`, and crosses mark the three poles.

Repository development and CI now use Rust/Cargo 1.99.0. The declared minimum
supported Rust version remains 1.92. The GPUI package also preserves a Linux
`libc` compatibility bound in its published manifest, allowing fresh consumers
to resolve a version compatible with the legacy `xattr` dependency.

Rust crates, Python bindings, and the npm package are aligned at `0.15.0`.
The image and function helpers described above are Rust core APIs.
