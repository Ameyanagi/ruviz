# ruviz 0.13.0

Molecular views gain physical-radius spheres with consistent surface depth,
lighting, transparency, and picking across software and GPU rendering. The new
`spheres3d(&atoms)` builder works with GPUI, where shading can change without
resetting camera or selection. `.axes(false)` gives molecular scenes a clear
view with a small orientation cue. Molecular spheres preserve data-unit lengths
and keep a stable scale during rotation by default. Other plots can opt into
`stable_scale(true)` with a fixed X:Y:Z ratio; the web SDK exposes matching
`axisAspect(...)`, `equalScale()`, and `stableScale()` controls.

The web 3D builder now combines series through the Rust core. Scheduled errors
have an explicit retry path, and demos use the public SDK with accessible view
controls and series checkboxes. Bar preparation is shared across raster, SVG,
and legend placement, and contributor commands cover all three Rust workspaces.

Migration notes:

- Web 3D series methods now **append**. Use `clearSeries()` (raw:
  `clear_series()`) before adding replacement series.
- Exhaustive Rust matches on `AxisAspect3D` and `PickPrimitive3D` must handle
  the new `Data` and `Sphere` variants respectively.
- Prefer `detach()` for clearing 2D sessions and `dispose()` for cleanup.
  Historical `destroy()` behavior remains compatible.

Sphere transparency sorts faded atoms by center depth; intersecting transparent
surfaces can show ordering artifacts, and translucent faces remain unsupported.
Release measurements cover 100, 1,000, and 10,000 atoms plus real 8 Å Ru/RuO₂
clusters. Ordinary clusters perform well in software; the measured 10,000-sphere
case does not sustain a 16.7 ms worker frame budget.
