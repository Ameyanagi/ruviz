# ruviz 0.15.2

Typst-mode raster legends now fit their labels. The legend frame used to be
sized from each label's markup source rather than from the text Typst renders,
so labels such as `#text("...")`, `#super[2]` or `Fit $mu(E)$` left extra
space on the right of the legend box. Labels are now measured as rendered.
Plain-text labels and non-Typst legends are unchanged.

Rust crates, Python bindings, and the npm package are aligned at `0.15.2`.

Changes: [#196](https://github.com/Ameyanagi/ruviz/pull/196).
