# ruviz 0.15.1

Typst-mode plots can now export editable SVG text. Add
`.svg_native_text(true)` after `.typst(true)`, and labels without math or
markup, such as tick numbers, axis labels, legend entries and titles, are
written as SVG `<text>` at the baselines Typst computed, so the layout does not
move. Labels that need Typst math stay outlined and carry their source string
in `aria-label`, so they remain searchable. PDFs made from that SVG get
selectable text.

The option is off by default; existing SVG and PDF output is byte-identical.
Native text uses the viewer's installed copy of the font, so widths can differ
slightly where that font is missing. PNG, other raster output and GPUI
rendering are unchanged.

This release also pins the WASM + Web CI job to `ubuntu-24.04`, where
Playwright can install its browsers. Rust crates, Python bindings, and the npm
package are aligned at `0.15.1`.
