# ruviz 0.14.1

PNG line series now use round joins and caps in the batched rendering path.
This removes triangular spikes from dense, noisy curves at wide line widths
and makes their strokes consistent with the other polyline rendering paths.
The minimum stroke width is also consistent with direct polyline rendering.

The fix covers solid and dashed lines, including clipped lines and runs
separated by non-finite data. Existing batching and cache behavior are retained.
No API changes are required.

Fixes [#186](https://github.com/Ameyanagi/ruviz/issues/186).
